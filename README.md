## 🗂️ Dataset Sources & Organisation

The dataset pipeline organizes images across two primary distributions:

1. **In-Domain Collection (CIFAKE)**:
   - Real photographic images (`cifar10`)
   - Synthetic AI images generated by latent diffusion (`stable-diffusion-1.4`)

2. **Out-of-Domain Collection (GenImage)**:
   - Real photographic baselines
   - Diffusion-based generation (`stable-diffusion`)
   - Modern generative models: Midjourney v5 (`midjourney`) and BigGAN (`biggan`)
